AI Usage
Which AI Tools I Used and What For
I used Copilot throughout parts of the project as a learning and mentoring tool rather than using it to generate the whole project.
I chose to use copilot as in my experience the other main LLM models (i.e claude and chatgpt) ofthen generate the whole code without any real explanation. I primarily used copilot in supporting my learning and in a similar way I would use other resources such as stackoverflow and other fourms. 
Any code that it generated I made sure it explained each step in detail and frequently asked questions about it to ensure that I had a clear understanding on what was being generated.
